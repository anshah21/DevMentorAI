# DevMentorAI

## Overview

DevMentorAI is an AI-powered code review and learning assistant designed for students and early-career developers. Users can paste code or upload source files and receive AI-generated feedback, code improvements, complexity analysis, and learning recommendations.

---

## Features

- AI-Powered Code Review
- Bug Detection
- Code Quality Analysis
- Time Complexity Analysis
- Space Complexity Analysis
- Learning Recommendations
- Source File Upload
- Code Statistics Panel
- Multi-Language Support

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Flask
- Python

### AI
- Google Gemini API

## Workflow

Input → Frontend → Flask Backend → Gemini API → AI Analysis → Results Display

---

## Setup

1. Clone repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Create .env file

```env
GEMINI_API_KEY=YOUR_API_KEY
```

4. Run Flask backend

```bash
python app.py
```

5. Open frontend

```text
index.html
```
